# Changelog

All notable changes to `laravel-vector-schema` will be documented in this file.

## v1.0.12 - 2026-11-03

- Align Composer author and keyword metadata with Eloquage.
- Set the PHPStan analysis script to a 512 MB memory limit.

## v1.0.11 - 2026-11-03

Release the package with Composer identity under the eloquage vendor namespace. This release contains the package metadata and documentation rename; runtime behavior is unchanged.

## v1.0.10 - 2026-10-23

Improve vector serialization and cosine compatibility across supported database drivers. Add SQLite execution and database integration coverage. See README for driver-specific behavior.
